# Relativistic-Adversarial-Feedback

This repository provides the official codebase and resources for RAF as described in our research. For the purposes of peer review, this repository is currently anonymous and will remain so until the publication process is complete, after which it will be de-anonymized with full author and project details.
## Prerequisites
1. Download the pretrained model WavLM from [this link](https://drive.google.com/file/d/12-cB34qCTvByWT-QtOcZaqwwO21FLSqU/view).
2. Install dependencies.
```
pip install -r requirements.txt
```

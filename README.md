# Relativistic-Adversarial-Feedback

This repository holds the codes to implement Relativistic Adversarial Feedback (RAF). 

## Prerequisites
1. Download the pretrained model WavLM from [this link](https://drive.google.com/file/d/12-cB34qCTvByWT-QtOcZaqwwO21FLSqU/view).
2. Install dependencies.
```
pip install -r requirements.txt
```
